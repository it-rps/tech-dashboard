### Business rules (from skill references)
- **Rule Set A:** Stock mutations → single RPC, never multiple client calls
- **Rule Set B:** Reserve = `qty_reserved++` only. Deduct at close via `issue_stock_fifo()`.
- **Rule Set C:** FIFO for COGS, WAC for stock value, Last for pricing
- **Rule Set D:** `job_kind` from `customers.kind`. Dealer/walkin = commission_eligible. Internal = cost price, no commission.
- **Rule Set E:** Cost fields filtered at query layer (`canSeeCost(role)`), never just UI
- **Rule Set H:** Doc numbers generated in DB, never TypeScript
- **Rule Set I:** Warranty days = `products.warranty_days ?? app_settings.default_warranty_days`
- **Rule Set L:** `device_imei` required to close. `stock_items` only for `track_serial = true`.
- **Rule Set K:** All money via `calcTax()`/`round2()`/`formatTHB()`

## Patterns established
- **Server Action:** `"use server"` → zodSchema.safeParse → requireRole → supabase/RPC → revalidatePath
- **Money:** satang cents (Math.round(n*100)), use calcTax() (exclusive/inclusive/none)
- **Query:** `import "server-only"` + createClient() + typed
- **Form:** useForm + Controller (NOT defaultValue + hidden input for selects) + zodResolver
- **Role gates:** requireRole(["owner","manager"]) for write; canSeeCost for read
- **Doc numbers:** in DB via BEFORE INSERT triggers — never TS
- **RPC pattern:** complex multi-table ops → single Postgres function
- **Insert with trigger-generated columns:** use `const payload: any = {...}` to avoid TS errors
